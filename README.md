# Complete DSA

A personal repository for practicing **Data Structures and Algorithms (DSA)** while preparing for software engineering interviews.

## Goals

- Strengthen problem-solving and algorithmic thinking
- Practice choosing appropriate data structures
- Improve time and space complexity analysis
- Keep solutions organized for revision

## Suggested Topic Structure

As the repository grows, organize solutions by topic:

- Arrays and strings
- Searching and sorting
- Hashing
- Recursion and backtracking
- Linked lists
- Stacks and queues
- Trees and graphs
- Greedy algorithms
- Dynamic programming

Only mark a topic as completed when its solutions have actually been added.

## How to Use

1. Browse the source files by topic or problem.
2. Read the approach before reviewing the implementation.
3. Test solutions against edge cases.
4. Record time and space complexity in each solution where useful.

## Recommended Solution Format

For each problem, include:

- Problem name and short description
- Approach
- Time complexity
- Space complexity
- Implementation
- Edge cases tested

## Language

Solutions should identify the programming language used in each file. Add language-specific build or run instructions as the repository needs them.
